La URL del servidor es `https://app.ringwise.example/api/mcp`. Si usa una implementación autoalojada, reemplace `app.ringwise.example` por su propio dominio. ChatGPT se conecta a ella desde internet, así que un Ringwise autoalojado necesita una dirección HTTPS pública.

Consulte [Servidor MCP](/es/ai/mcp) para ver qué herramientas habilita cada permiso.

## ChatGPT

ChatGPT conecta servidores MCP personalizados desde su página **Plugins**, en la web. En los planes Business, Enterprise y Edu, ChatGPT puede usar todas las herramientas de Ringwise, incluidas las que modifican datos. En Pro, solo puede usar las herramientas que leen datos. En un espacio de trabajo Business, solo los administradores y propietarios pueden agregar un servidor personalizado. En Enterprise y Edu, los administradores pueden dar ese permiso a otros miembros.

<Steps>
  <Step title="Agregue el servidor">
    En ChatGPT, vaya a **Plugins**, haga clic en **+** y luego en **Add custom MCP server**. Llámelo `Ringwise` y pegue la URL del servidor en **Connection**. No necesita activar antes el modo de desarrollador.
  </Step>
  <Step title="Elija OAuth">
    Elija **OAuth** como autenticación y deje vacíos el ID de cliente y el secreto: ChatGPT se registra solo en Ringwise. Lea la advertencia de riesgos, marque **I understand and want to continue** y haga clic en **Create as a plugin**.
  </Step>
  <Step title="Inicie sesión y elija el acceso">
    ChatGPT abre Ringwise. Inicie sesión, elija el espacio de trabajo, desmarque lo que ChatGPT no deba hacer y haga clic en **Permitir acceso**.
  </Step>
  <Step title="Instale el plugin">
    Revise las herramientas que encontró ChatGPT y luego instale el plugin. En un chat nuevo, escriba `@` y seleccione Ringwise.
  </Step>
</Steps>

Para desconectarlo, vaya a **Configuración** > **Claves de API** en Ringwise y haga clic en **Desconectar** junto a ChatGPT, en **Conexiones MCP**.

## Responses API de OpenAI

La Responses API llama por usted a los servidores MCP remotos. Pase una clave de API en `headers`:

```bash
curl https://api.openai.com/v1/responses \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "content-type: application/json" \
  -d '{
    "model": "gpt-6-luna",
    "tools": [{
      "type": "mcp",
      "server_label": "ringwise",
      "server_url": "https://app.ringwise.example/api/mcp",
      "headers": { "Authorization": "Bearer '"$RINGWISE_API_KEY"'" },
      "require_approval": "always"
    }],
    "input": "Who called yesterday and asked for a callback?"
  }'
```

`require_approval: "always"` hace que la API se detenga antes de cada llamada a una herramienta para que su código pueda confirmarla. Relájelo solo para claves con permisos de lectura.

## Codex

La aplicación de escritorio de ChatGPT, la CLI de Codex y la extensión de Codex para IDE comparten una misma configuración MCP, así que solo agrega Ringwise una vez. Agregue el servidor e inicie sesión:

```bash
codex mcp add ringwise --url https://app.ringwise.example/api/mcp
codex mcp login ringwise
```

`codex mcp login` abre Ringwise en su navegador. Inicie sesión, elija el espacio de trabajo, desmarque lo que Codex no deba hacer y haga clic en **Permitir acceso**. Codex se registra solo en Ringwise, así que no necesita un ID de cliente ni un secreto. Luego pida a Codex que llame a `get_business` para comprobar la conexión.

### Codex con una clave de API

Para usar una clave de API en su lugar, agregue Ringwise a `~/.codex/config.toml`. Codex lee la clave de la variable de entorno que usted indique:

```toml ~/.codex/config.toml
[mcp_servers.ringwise]
url = "https://app.ringwise.example/api/mcp"
bearer_token_env_var = "RINGWISE_API_KEY"
```

Exporte `RINGWISE_API_KEY` en su shell antes de iniciar Codex.
